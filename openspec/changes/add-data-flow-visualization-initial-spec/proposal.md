# Change: Establish initial specification for the Data Flow Visualization Tool

## Why
This project is starting from scratch. The initial requirements must be consolidated into OpenSpec so we have a single durable, versionable source of truth for what the product is and how it must behave.

## What Changes
- Introduce an initial OpenSpec capability specification that captures the complete product definition for the Data Flow Visualization Tool.
- Explicitly require English-only project communication for documentation and code comments (even if prompts are written in Russian).
- Provide an implementation checklist for the upcoming build stage (apply).

## Impact
- Affected specs: **NEW** `data-flow-visualization`
- Affected code: none (proposal/spec only)
